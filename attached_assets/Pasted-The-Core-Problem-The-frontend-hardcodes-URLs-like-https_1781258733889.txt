The Core Problem
The frontend hardcodes URLs like https://api.thejourney-ma.org/attached_assets/... and the backend seeders/controllers reference paths like /attached_assets/generated_images/... — but the Laravel backend has zero public/ directory in the codebase, and there is no route, controller, or middleware that serves /attached_assets/ at all. These files only exist on the live server's disk, not in the repo.

Diagnosis: 3 Separate Issues
🔴 Issue 1 — Vite proxy sends /api to dead localhost:3001 (dev broken)
In vite.config.ts, the /api proxy rule points to LOCAL_API = "http://localhost:3001" (the old removed Express server), not to the Laravel API:
tsproxy: {
  "/api": {
    target: LOCAL_API,  // ← localhost:3001 — this server doesn't exist anymore!
    ...
  },
In dev, every fetch('/api/...') call goes to a dead server and gets a 503. Fix: change the proxy target to LARAVEL_API.

🔴 Issue 2 — ~23 components use raw fetch('/api/...') instead of apiFetch
In production, apiFetch correctly prepends VITE_API_BASE_URL (https://api.thejourney-ma.org) to the path. But components like Header.tsx, Footer.tsx, ClubsWithMap.tsx, Events.tsx, etc. call raw fetch('/api/...') directly — which in production hits the frontend host (thejourney-ma.org/api/...) instead of the backend.

🟡 Issue 3 — CORS config missing the www subdomain variant and is HTTP-only for dev
config/cors.php allowed_origins_patterns includes '#^http://.*$#' which is very broad (accepts any HTTP origin). That's fine for dev but if the deployed frontend ever uses a URL not listed in allowed_origins, it'll get blocked.

Fix the 23 components using raw fetch('/api/...') — you need to either:
Option A (quickest): Replace raw fetch calls with apiFetch from @/lib/apiFetch. Example:
ts// BEFORE (Header.tsx, ClubsWithMap.tsx, etc.)
const res = await fetch("/api/cities");

// AFTER
import { apiFetch } from "@/lib/apiFetch";
const res = await apiFetch("/api/cities");
Option B (zero component changes): Add a global fetch interceptor in main.tsx that prepends VITE_API_BASE_URL for relative /api paths in production:
ts// src/main.tsx — add at the top before ReactDOM.createRoot
const API_BASE = import.meta.env.VITE_API_BASE_URL ?? '';
if (API_BASE) {
  const _fetch = window.fetch.bind(window);
  window.fetch = (input, init?) => {
    if (typeof input === 'string' && input.startsWith('/api')) {
      input = `${API_BASE}${input}`;
    }
    return _fetch(input, init);
  };
}
Option B is the fastest — one change fixes all 23 components at once.
